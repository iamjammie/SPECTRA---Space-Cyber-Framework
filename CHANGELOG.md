# Changelog

## v0.2.0
- Added the offline SPECTRA Navigator (`index.html`): matrix, threat surface, attack paths, threat actors, incidents, controls and assessment views, with filtering, overlays, export and import.
- Published the dataset as JSON in `framework/data/`: 120 techniques across nine states, each with segments, assets, ways in, capability tier, evidence label, detection, controls and a safe assessment.
- Expanded controls from 20 to 36, grouped by Govern, Identify, Protect, Detect, Respond and Recover, each with a verification test.
- Added 12 mission effects and 16 detection data sources.
- Added 20 threat actor profiles and 36 incident and research records (1986 to 2026) with attribution labels and sources.
- Added 10 worked attack paths with defensive breakpoints.
- Added JSON Schemas, validation and build scripts, CI, Pages deployment, methodology, scoring model, lab guidance, exercise catalogue, six playbooks and a sample assessment.

## v0.1.0
- Introduced mission-first SPECTRA model.
- Added 120 custom assessment techniques.
- Added 20 defensive controls.
- Added mission-effect taxonomy.
- Added scoring, maturity model, practical playbooks and exercise catalogue.
- Added machine-readable schema and CI validation.
