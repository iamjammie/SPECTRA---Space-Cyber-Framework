# Roadmap

## Done in v0.2
- Dataset: 120 techniques, 36 controls, 12 mission effects, 16 detection data sources.
- Threat actor and incident records with attribution labels and sources.
- Ten worked attack paths.
- Offline navigator with filtering, overlays and an assessment workspace.

## Next
- Sub-techniques for the most crowded states (Positioning, Control).
- Per-technique crosswalk to SPARTA and SPACE-SHIELD identifiers, added only where each mapping has
  been checked against the current published version.
- Path builder in the navigator: assemble and save your own attack path.
- STIX 2.1 export of the dataset.
- Detection notes per data source with example telemetry.
- Community review of capability tiers and control mappings.

## Not planned
- Exploit code, target lists or operational parameters for real systems.
